# Banco de questões — Administração Geral — Módulo 2

Este diretório guarda o banco canônico e o simulado do módulo.

## Escopo

- teorias da Administração;
- processo administrativo gerencial;
- estruturas organizacionais;
- centralização e descentralização gerencial.

## Situação das fontes oficiais

Nenhuma questão oficial da FEPESE foi incluída até agora. A pesquisa inicial não forneceu, para este módulo, um conjunto com caderno oficial, gabarito definitivo e relação direta com as cinco aulas. A ausência será mantida de forma clara até que a verificação exigida pelo `QUESTION_GUIDE.md` seja concluída.

Questões autorais não serão usadas para afirmar comportamento da banca.

## Arquivos

- `banco-comentado.md`: questões autorais comentadas;
- `matriz.md`: controle de tema, objetivo, dificuldade e gabarito;
- `simulado.md`: questões inéditas do simulado;
- `fontes.md`: pesquisa, limites e futuras fontes oficiais.
