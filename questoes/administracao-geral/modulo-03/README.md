# Banco de questões — Administração Geral — Módulo 3

Este diretório guarda o banco canônico e o simulado do módulo.

## Escopo

- modelos patrimonialista, burocrático, gerencial e societal;
- Nova Gestão Pública;
- governança pública organizacional.

## Situação das fontes oficiais

Nenhuma questão oficial da FEPESE foi incluída. A pesquisa inicial não confirmou, para este módulo, caderno oficial, gabarito definitivo e relação direta com as aulas em quantidade suficiente para publicação.

As questões autorais treinam o edital, mas não servem para afirmar comportamento da banca.

## Arquivos

- `banco-comentado.md`: questões autorais comentadas;
- `matriz.md`: controle de tema, dificuldade e gabarito;
- `simulado.md`: questões inéditas;
- `fontes.md`: fontes, pesquisa e limites.
