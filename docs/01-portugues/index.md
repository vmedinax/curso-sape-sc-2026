# Língua Portuguesa

Esta disciplina ensina a resolver as oito questões de Língua Portuguesa previstas para o cargo de Analista Técnico Administrativo II. O ponto de partida é o texto: primeiro, você aprende a localizar e justificar respostas; depois, estuda os recursos linguísticos que constroem o sentido.

## Comece pelo Módulo 1

O primeiro módulo não pressupõe conhecimento de gramática. Ele ensina seis operações de prova: localizar, resumir, inferir, reconhecer implícitos, analisar argumentos e identificar gêneros e tipos textuais.
