# Resumo do Módulo 2

| Decisão de prova | Pergunta-chave | Método |
|---|---|---|
| adequação | quem fala, com quem, para quê e onde? | CIFRA |
| sentido | que paráfrase funciona no contexto? | LUPA |
| figura | qual mecanismo produz qual efeito? | MEP |
| continuidade | quem é retomado e qual relação se forma? | REFER |

## Confusões que decidem alternativas

- variedade linguística não é defeito pessoal;
- formalidade não é linguagem rebuscada;
- conotação exige efeito contextual, não palavra isolada;
- figura deve ser explicada antes de ser nomeada;
- coesão é ligação linguística; coerência é compatibilidade de ideias;
- substituir palavras pode alterar precisão ou referente.

## Ação na prova

Marque o trecho relevante, produza uma paráfrase curta e só depois escolha o termo técnico. Se a alternativa nomeia corretamente, mas explica efeito ou relação errada, elimine-a.
