# Resumo do Módulo 3

| Decisão | Rota | Alerta |
|---|---|---|
| tonicidade | separar → ouvir → contar do fim | acento gráfico não é a tônica |
| encontros | separar → contar sons → classificar | letra não equivale sempre a fonema |
| grafia | família → formação → VOLP | pronúncia não resolve tudo |
| acentuação | tônica → estrutura → regra | grupos têm critérios diferentes |
| hífen | elementos → fronteira → critério → consulta | exemplo isolado não vira regra |
| palavras parecidas | contexto → paráfrase → palavra | semelhança formal não é sentido |

## Regras que merecem recuperação

- proparoxítonas são sempre acentuadas;
- ditongo permanece numa sílaba; hiato separa vogais em sílabas distintas;
- dígrafo representa um fonema com duas letras;
- *ideia*, *heroico*, *voo* e *leem* não recebem os antigos acentos;
- *anti-inflamatório*, *autoescola*, *antissocial* e *super-homem* seguem fronteiras diferentes;
- *ratificar* confirma; *retificar* corrige.

## Ação na prova

Não marque pela aparência. Reconstrua a palavra em camadas e use a fonte oficial quando a regularidade não decidir.
