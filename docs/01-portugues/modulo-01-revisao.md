# Revisão de 5 minutos — Módulo 1

Feche as aulas e responda antes de conferir.

## Minuto 1 — localizar

O que precisa permanecer igual numa paráfrase? **Agente, ação, tempo, condição, quantidade e intensidade relevantes.**

## Minuto 2 — hierarquizar

Complete: assunto é o campo **amplo**; tema é o **recorte**; ideia principal é a **afirmação central**.

## Minuto 3 — inferir

Qual é o limite? A conclusão deve ser a menor compatível com as **pistas** e não pode converter possibilidade em certeza.

## Minuto 4 — implícitos e argumento

*Voltou a* pressupõe ocorrência anterior e retomada. Tese responde “o que se defende?”; argumento, “por quê?”.

## Minuto 5 — classificar

Gênero é a forma social ligada à finalidade; tipo é o modo de organização. Narração, descrição, exposição, argumentação e injunção podem coexistir.

## Mapa mental

```text
LEITURA DE PROVA
├── declarado → localizar → conferir equivalência
├── centro → assunto → tema → ideia principal
├── concluído → pistas → inferência → teste
├── não dito → gatilho → pressuposto
│             contexto → intenção
├── defendido → tese → argumentos → apoios → objeção/refutação
└── forma do texto
    ├── gênero → finalidade + circulação
    └── tipo → narrar | descrever | expor | argumentar | orientar
```

## Revisão integradora

Escolha um comunicado público curto. Em dez minutos, marque uma informação explícita, escreva a ideia principal, formule uma inferência controlada, identifique a finalidade, diga o gênero e indique o tipo predominante. Toda resposta deve apontar uma pista.
