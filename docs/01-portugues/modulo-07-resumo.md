# Resumo do Módulo 7

## Decisão antes do sinal

```text
estrutura → relação → posição → sinal → efeito de sentido
```

| Situação | Decisão |
|---|---|
| sujeito + verbo | não separar |
| verbo + complemento | não separar |
| enumeração, vocativo, aposto | separar conforme a função |
| oração substantiva + regente | preservar a ligação |
| adjetiva restritiva | sem vírgulas |
| adjetiva explicativa | com vírgulas |
| adverbial anteposta/intercalada | marcar o deslocamento |
| blocos já pontuados | considerar ponto e vírgula |
| conteúdo anunciado | considerar dois-pontos |

## Regra de prova

Não pergunte primeiro “onde respiro?”. Pergunte “que termos ou orações estão ligados e qual trabalho o sinal realiza?”. Uma troca pode manter correção e alterar alcance ou destaque.
