# Flashcards do Módulo 8

<section class="lesson-goal"><h2>Nestes cartões você vai treinar</h2><p>os 48 conceitos essenciais do maior módulo da disciplina.</p></section>

## Dados e estatística

??? question "1. O que é dado?"
    Registro bruto.
??? question "2. O que é informação?"
    Dado organizado em contexto.
??? question "3. O que é variável?"
    Característica que assume valores.
??? question "4. O que é unidade observada?"
    Aquilo sobre o que cada registro fala.
??? question "5. O que é fonte primária?"
    Dado coletado diretamente para a análise.
??? question "6. O que é fonte secundária?"
    Dado já existente.
??? question "7. Vazio é zero?"
    Não.
??? question "8. O que é metadado?"
    Explicação sobre significado e origem do dado.
??? question "9. O que é média?"
    Soma dividida pela quantidade.
??? question "10. O que é mediana?"
    Centro dos dados ordenados.
??? question "11. O que é moda?"
    Valor mais frequente.
??? question "12. O que é amplitude?"
    Maior valor menos menor valor.
??? question "13. O que é denominador?"
    Total usado na divisão.
??? question "14. O que é taxa?"
    Número de casos em relação a uma base.

## Apresentação e decisão

??? question "15. Para que serve painel?"
    Acompanhamento rápido.
??? question "16. Para que serve relatório?"
    Apresentação e análise com contexto.
??? question "17. Qual gráfico mostra tendência?"
    Linha.
??? question "18. Qual visual mostra valores exatos?"
    Tabela.
??? question "19. Cor substitui regra?"
    Não.
??? question "20. O que é evidência?"
    Informação que sustenta ou questiona afirmação.
??? question "21. Evidência decide sozinha?"
    Não.
??? question "22. O que é incerteza?"
    Aquilo que não se sabe com segurança.
??? question "23. O que é viés cognitivo?"
    Atalho mental que pode gerar erro.
??? question "24. O que é custo afundado?"
    Recurso passado que não pode ser recuperado.

## Documentos e protocolo

??? question "25. O que é documento de arquivo?"
    Registro ligado a uma atividade.
??? question "26. O que é suporte?"
    Meio em que o registro existe.
??? question "27. O que é gestão de documentos?"
    Procedimentos da produção à destinação.
??? question "28. Quais são as fases?"
    Corrente, intermediária e permanente.
??? question "29. O que é classificação?"
    Organização conforme funções e atividades.
??? question "30. O que é avaliação documental?"
    Definição de valor, prazo e destino.
??? question "31. O que é temporalidade?"
    Prazo de guarda.
??? question "32. O que é destinação?"
    Eliminação autorizada ou guarda permanente.
??? question "33. Digitalizar autoriza eliminar?"
    Não automaticamente.
??? question "34. O que é protocolo?"
    Controle de entrada, registro, movimento e saída.
??? question "35. O que é tramitação?"
    Caminho do documento.
??? question "36. O que é autuação?"
    Formação oficial de processo.
??? question "37. O que é proveniência?"
    Origem do conjunto documental.
??? question "38. O que é organicidade?"
    Relação natural entre documentos da atividade.

## Documentos administrativos e conhecimento

??? question "39. Para que serve relatório?"
    Apresentar fatos, método e resultados.
??? question "40. O que é parecer?"
    Opinião técnica ou jurídica fundamentada.
??? question "41. O que é nota técnica?"
    Análise técnica de assunto ou proposta.
??? question "42. O que é despacho?"
    Manifestação ou decisão no processo.
??? question "43. O que registra uma ata?"
    Reunião, participantes e decisões.
??? question "44. O que é conhecimento?"
    Entendimento usado para agir.
??? question "45. O que é conhecimento explícito?"
    Saber registrado.
??? question "46. O que é conhecimento tácito?"
    Saber ligado à experiência.
??? question "47. O que é comunidade de prática?"
    Grupo que aprende junto sobre trabalho comum.
??? question "48. O que é aprendizagem organizacional?"
    Aprendizado incorporado à forma de funcionar.
