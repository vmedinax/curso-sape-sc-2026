## Aula 1

??? question "1. O que é processo?"
    Atividades relacionadas que transformam entradas em saídas.
??? question "2. O que é entrada?"
    Algo que inicia ou alimenta o trabalho.
??? question "3. O que é saída?"
    Entrega produzida pelo processo.
??? question "4. O que significa ponta a ponta?"
    Da necessidade inicial até a entrega final.
??? question "5. Processo é unidade?"
    Não. Processo é fluxo; unidade é estrutura.
??? question "6. O que é BPM?"
    Gerenciamento contínuo dos processos.
??? question "7. O que faz o dono do processo?"
    Acompanha o fluxo como um todo.

## Aula 2

??? question "8. O que é mapeamento?"
    Registro organizado do funcionamento do processo.
??? question "9. O que é AS IS?"
    Situação atual.
??? question "10. O que é TO BE?"
    Situação futura desejada.
??? question "11. O que é gargalo?"
    Ponto que limita o fluxo.
??? question "12. O que é retrabalho?"
    Tarefa refeita por falha.
??? question "13. O que é sintoma?"
    Efeito visível de um problema.
??? question "14. O que é causa?"
    Fator que produz o problema.
??? question "15. Por que ouvir quem executa?"
    Para conhecer a prática e suas dificuldades.

## Aula 3

??? question "16. O que é qualidade?"
    Adequação à necessidade e aos requisitos.
??? question "17. O que é requisito?"
    Condição que a entrega precisa cumprir.
??? question "18. Qual é a ordem do PDCA?"
    Planejar, executar, verificar e agir.
??? question "19. O que é padrão?"
    Referência aprovada para executar o trabalho.
??? question "20. Por que testar uma melhoria?"
    Para aprender com menor risco.
??? question "21. O que é ação corretiva?"
    Ação sobre a causa de problema ocorrido.
??? question "22. Correção imediata sempre retira a causa?"
    Não.

## Aula 4

??? question "23. O que é eficiência?"
    Relação entre recursos e produtos.
??? question "24. O que é eficácia?"
    Alcance de objetivo ou meta.
??? question "25. O que é efetividade?"
    Efeito produzido na realidade.
??? question "26. O que é economicidade?"
    Obter recurso adequado em custo, quantidade e qualidade.
??? question "27. Bater a meta prova efetividade?"
    Não. É preciso observar a mudança real.
??? question "28. Economizar prova eficácia?"
    Não. É preciso verificar a meta.
??? question "29. Palavra-chave de eficiência?"
    Recursos.

## Aula 5

??? question "30. O que é mudança organizacional?"
    Alteração relevante na forma de funcionar.
??? question "31. O que é cultura organizacional?"
    Hábitos, valores e formas de agir do grupo.
??? question "32. O que é resistência?"
    Oposição, atraso ou insegurança diante da mudança.
??? question "33. Comunicação substitui capacitação?"
    Não.
??? question "34. O que é projeto-piloto?"
    Teste em pequena escala.
??? question "35. O que é institucionalização?"
    Entrada da mudança na rotina e nas regras.
??? question "36. Como saber se a mudança funcionou?"
    Acompanhar adoção, resultado, erros e efeitos inesperados.
