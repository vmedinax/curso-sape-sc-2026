# Resumo do Módulo 6

<section class="lesson-goal"><h2>Neste resumo você vai organizar</h2><p>os conceitos que levam uma iniciativa da escolha à entrega e ao benefício.</p></section>

## Quatro formas de organizar o trabalho

| Conceito | Ideia principal |
|---|---|
| Processo | trabalho recorrente |
| Projeto | esforço temporário com entrega única |
| Programa | projetos relacionados coordenados para benefícios conjuntos |
| Portfólio | carteira priorizada para apoiar a estratégia |

## Ciclo do projeto

```text
iniciação → planejamento → execução ↔ monitoramento e controle → encerramento
```

Iniciação esclarece. Planejamento organiza. Execução produz. Monitoramento compara e corrige. Encerramento aceita, fecha e registra aprendizado.

## Plano do projeto

- objetivo: mudança buscada;
- entrega: o que será produzido;
- escopo: fronteira do trabalho;
- cronograma: atividades no tempo;
- marco: ponto importante;
- dependência: ligação entre atividades;
- recurso: meio necessário;
- risco: evento incerto;
- responsável: pessoa que responde pelo trabalho.

## Acompanhar

Observe escopo, prazo, recursos, qualidade, riscos, problemas e benefícios. Linha de base é a referência aprovada. Desvio é a diferença entre plano e realizado.

```text
entrega → uso → resultado → benefício
```

## Portfólio

Seleciona, prioriza e equilibra iniciativas. Um projeto pode ser bom sozinho e ainda não caber na carteira. Critérios claros evitam que toda proposta seja tratada como prioridade máxima.

!!! warning "Isso costuma confundir"
    Programa exige relação entre projetos. Portfólio pode reunir componentes sem relação direta, desde que apoiem a estratégia.

## Checklist

- [ ] Separo os quatro conceitos.
- [ ] Ordeno o ciclo.
- [ ] Separo risco e problema.
- [ ] Separo entrega e benefício.
- [ ] Explico seleção, prioridade e balanceamento.
