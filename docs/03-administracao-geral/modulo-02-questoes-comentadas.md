## Como usar

1. Responda antes de abrir o comentário.
2. Marque se acertou com segurança, com dúvida ou por chute.
3. Leia todas as alternativas, mesmo quando acertar.
4. Use o link indicado para voltar à aula certa.

Não há questão oficial da FEPESE neste conjunto. As vinte questões são autorais. A pesquisa ainda não confirmou uma amostra com cadernos e gabaritos definitivos que cumpra todas as regras do projeto para este módulo.
