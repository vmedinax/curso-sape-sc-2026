# Flashcards do Módulo 6

<section class="lesson-goal"><h2>Nestes cartões você vai treinar</h2><p>conceitos, planejamento, acompanhamento e portfólio.</p></section>

## Conceitos e ciclo

??? question "1. O que é projeto?"
    Esforço temporário para entrega única.
??? question "2. Temporário significa curto?"
    Não. Significa ter começo e fim.
??? question "3. O que é processo?"
    Trabalho recorrente.
??? question "4. O que é programa?"
    Projetos relacionados coordenados para benefícios conjuntos.
??? question "5. O que é benefício?"
    Melhora produzida pelas entregas.
??? question "6. Quais são as fases gerais?"
    Iniciação, planejamento, execução, monitoramento e controle, encerramento.
??? question "7. Quem são stakeholders?"
    Partes interessadas.

## Planejamento e execução

??? question "8. O que é objetivo?"
    Mudança buscada.
??? question "9. O que é entrega?"
    Produto, serviço ou resultado produzido.
??? question "10. O que é escopo?"
    Fronteira do trabalho e das entregas.
??? question "11. O que é cronograma?"
    Organização das atividades no tempo.
??? question "12. O que é marco?"
    Ponto importante sem duração.
??? question "13. O que é dependência?"
    Ligação que condiciona uma atividade a outra.
??? question "14. O que é risco?"
    Evento incerto que pode afetar objetivo.
??? question "15. O que é problema?"
    Situação indesejada que já ocorreu.

## Acompanhamento

??? question "16. O que é linha de base?"
    Referência aprovada para comparação.
??? question "17. O que é desvio?"
    Diferença entre plano e realizado.
??? question "18. Tarefas concluídas medem todo o valor?"
    Não.
??? question "19. Entrega e benefício são iguais?"
    Não.
??? question "20. O que são lições aprendidas?"
    Conhecimento registrado para o futuro.
??? question "21. O que inclui o encerramento?"
    Aceitação, pendências, fechamento e aprendizado.

## Portfólio

??? question "22. O que é portfólio?"
    Carteira de iniciativas ligada à estratégia.
??? question "23. Componentes precisam ser relacionados?"
    Não.
??? question "24. O que é priorizar?"
    Definir o que recebe recursos antes.
??? question "25. O que é balancear?"
    Formar uma carteira viável.
??? question "26. Projeto bom pode sair da carteira?"
    Sim.
??? question "27. Portfólio é temporário?"
    A carteira pode ser contínua e revista.
??? question "28. Qual é a função da governança do portfólio?"
    Direcionar, decidir e acompanhar a carteira.
