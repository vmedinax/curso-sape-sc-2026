## Aula 1 — Planejamento estratégico

??? question "1. O que é estratégia?"
    Conjunto de escolhas que orienta o rumo e as prioridades. **Origem:** Aula 1.

??? question "2. O que é planejamento estratégico?"
    Construção organizada da finalidade, do futuro, dos desafios, dos objetivos e das principais ações. **Origem:** Aula 1.

??? question "3. O que é missão?"
    Razão atual de existência da organização. **Origem:** Aula 1.

??? question "4. O que é visão?"
    Situação futura desejada. **Origem:** Aula 1.

??? question "5. O que são valores institucionais?"
    Princípios de conduta que orientam decisões e relações. **Origem:** Aula 1.

??? question "6. Na análise SWOT, quais fatores são internos?"
    Forças e fraquezas. **Origem:** Aula 1.

??? question "7. Na análise SWOT, quais fatores são externos?"
    Oportunidades e ameaças. **Origem:** Aula 1.

??? question "8. Qual é a diferença entre objetivo e iniciativa?"
    Objetivo indica a mudança; iniciativa é ação organizada para apoiá-la. **Origem:** Aula 1.

## Aula 2 — Níveis

??? question "9. O que define o nível estratégico?"
    Rumo e resultados amplos da organização. **Origem:** Aula 2.

??? question "10. O que define o nível tático?"
    Planos de áreas ou unidades que traduzem a estratégia. **Origem:** Aula 2.

??? question "11. O que define o nível operacional?"
    Tarefas, responsáveis, prazos e meios do dia a dia. **Origem:** Aula 2.

??? question "12. Quais três palavras ajudam a lembrar os níveis?"
    Rumo, área e tarefa. **Origem:** Aula 2.

??? question "13. Prazo basta para classificar o nível?"
    Não. Alcance e tipo de decisão são os critérios principais. **Origem:** Aula 2.

??? question "14. O que é desdobrar a estratégia?"
    Transformar objetivo geral em planos de áreas, ações e tarefas ligadas. **Origem:** Aula 2.

??? question "15. O que é alinhamento estratégico?"
    Fazer objetivos, planos e tarefas apontarem para a mesma direção. **Origem:** Aula 2.

## Aula 3 — Planejamento governamental

??? question "16. O que é planejamento governamental?"
    Organização das escolhas de governo para enfrentar problemas e entregar resultados ao longo do tempo. **Origem:** Aula 3.

??? question "17. Qual é a função geral do PPA?"
    Definir diretrizes, objetivos e metas para quatro anos. **Origem:** Aula 3.

??? question "18. Qual é a função geral da LDO?"
    Apresentar metas e prioridades e orientar o orçamento do ano seguinte. **Origem:** Aula 3.

??? question "19. Qual é a função geral da LOA?"
    Estimar receitas e fixar despesas para o exercício. **Origem:** Aula 3.

??? question "20. PPA, LDO e LOA precisam ser compatíveis?"
    Sim. As escolhas anuais precisam se ligar à direção mais ampla. **Origem:** Aula 3.

??? question "21. Inserir uma ação no plano autoriza sozinho o gasto?"
    Não. O gasto depende de autorização orçamentária e das demais regras aplicáveis. **Origem:** Aula 3.

## Aula 4 — Gestão por resultados

??? question "22. O que é gestão estratégica?"
    Acompanhamento e ajuste da execução para mantê-la ligada aos objetivos. **Origem:** Aula 4.

??? question "23. O que é gestão orientada para resultados?"
    Organização de decisões e acompanhamento a partir dos resultados públicos desejados. **Origem:** Aula 4.

??? question "24. Qual é a cadeia de resultados?"
    Recursos, atividades, entregas, resultados e impactos. **Origem:** Aula 4.

??? question "25. O que é atividade?"
    A ação realizada com os recursos. **Origem:** Aula 4.

??? question "26. O que é entrega?"
    Bem ou serviço produzido diretamente pela atividade. **Origem:** Aula 4.

??? question "27. O que é resultado?"
    Mudança observada depois do uso da entrega. **Origem:** Aula 4.

??? question "28. O que é impacto?"
    Efeito mais amplo e duradouro, influenciado por vários fatores. **Origem:** Aula 4.

## Aula 5 — Metas e acompanhamento

??? question "29. O que é objetivo?"
    A mudança que a organização deseja produzir. **Origem:** Aula 5.

??? question "30. O que é indicador?"
    Medida usada para acompanhar situação, atividade, entrega ou resultado. **Origem:** Aula 5.

??? question "31. O que é meta?"
    Valor desejado para um indicador, acompanhado de prazo. **Origem:** Aula 5.

??? question "32. O que é linha de base?"
    Valor inicial usado para comparar a evolução. **Origem:** Aula 5.

??? question "33. O que é monitoramento?"
    Acompanhamento regular para perceber avanço, atraso e necessidade de correção. **Origem:** Aula 5.

??? question "34. O que é avaliação?"
    Análise que julga valor, desempenho ou resultado com critérios e evidências. **Origem:** Aula 5.

??? question "35. Monitoramento e avaliação são iguais?"
    Não. Um acompanha regularmente; o outro aprofunda e julga uma pergunta. **Origem:** Aula 5.

??? question "36. Melhora depois da ação prova que ela causou o resultado?"
    Não. Outros fatores podem ter contribuído. **Origem:** Aula 5.
