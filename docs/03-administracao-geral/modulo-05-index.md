## A pergunta que guia o módulo

Como melhorar uma entrega sem olhar apenas para uma unidade ou para uma tarefa isolada?

```text
necessidade → processo atual → problema → processo melhorado → teste → acompanhamento
```

Você já sabe definir objetivo, meta e indicador. Agora verá onde o trabalho realmente acontece.
