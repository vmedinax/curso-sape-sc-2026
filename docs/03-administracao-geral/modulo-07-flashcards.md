# Flashcards do Módulo 7

<section class="lesson-goal"><h2>Nestes cartões você vai treinar</h2><p>conceitos, ciclo, desenho, execução e avaliação.</p></section>

## Conceitos

??? question "1. O que é política pública?"
    Resposta organizada, com participação do Estado, a problema coletivo.
??? question "2. O que é problema público?"
    Situação coletiva indesejada que merece resposta pública.
??? question "3. O que é política distributiva?"
    Entrega benefício a grupos ou áreas.
??? question "4. O que é redistributiva?"
    Muda distribuição de recursos ou oportunidades.
??? question "5. O que é regulatória?"
    Cria regras ou obrigações.
??? question "6. O que é constitutiva?"
    Organiza regras do funcionamento público.
??? question "7. O que são atores?"
    Pessoas e organizações que influenciam ou são afetadas.

## Agenda e ciclo

??? question "8. O que é agenda?"
    Problemas que recebem atenção relevante.
??? question "9. Entrar na agenda garante solução?"
    Não.
??? question "10. O ciclo é rígido?"
    Não.
??? question "11. O que é formulação?"
    Criação e comparação de alternativas.
??? question "12. O que é decisão?"
    Escolha autorizada entre caminhos.
??? question "13. Não agir pode ser escolha pública?"
    Sim.

## Diagnóstico e desenho

??? question "14. O que é diagnóstico?"
    Análise do problema, público, tamanho, causas e efeitos.
??? question "15. O que é público-alvo?"
    Grupo que a política pretende alcançar diretamente.
??? question "16. O que é focalização?"
    Direcionamento a grupo definido.
??? question "17. O que é universalização?"
    Oferta ampla conforme condições gerais.
??? question "18. O que é modelo lógico?"
    Caminho de recursos a impactos.
??? question "19. O que significa ex ante?"
    Antes da implantação ou expansão.
??? question "20. Qual é a cadeia lógica?"
    Insumos, atividades, produtos, resultados e impactos.

## Implementação

??? question "21. O que é implementação?"
    Ações que fazem a política funcionar.
??? question "22. O que significa top-down?"
    Olhar da direção central.
??? question "23. O que significa bottom-up?"
    Olhar da execução local.
??? question "24. O que é linha de frente?"
    Profissionais que atendem diretamente o público.
??? question "25. O que é discricionariedade?"
    Espaço de escolha permitido pelas regras.
??? question "26. O que é capacidade estatal?"
    Condições para decidir e executar.
??? question "27. Instrumento deve combinar com quê?"
    Com a causa do problema.

## Avaliação

??? question "28. O que é monitoramento?"
    Acompanhamento contínuo.
??? question "29. O que é avaliação?"
    Análise aprofundada guiada por pergunta.
??? question "30. O que significa ex post?"
    Depois do início da execução.
??? question "31. O que avalia o desenho?"
    A lógica da política.
??? question "32. O que avalia a implementação?"
    Funcionamento e alcance do público.
??? question "33. O que avalia resultados?"
    Mudanças observadas nos indicadores.
??? question "34. O que avalia impacto?"
    Mudança causada pela política.
??? question "35. O que é contrafactual?"
    Situação que ocorreria sem a política.
??? question "36. Correlação prova causa?"
    Não.
??? question "37. O que é viés de seleção?"
    Comparação frágil entre grupos inicialmente diferentes.
??? question "38. O que é validade interna?"
    Confiança na causa medida no grupo estudado.
??? question "39. O que é validade externa?"
    Possibilidade de aplicar conclusão a outros contextos.
??? question "40. Impacto positivo basta para expandir?"
    Não. Considere custo, alcance, justiça e capacidade.
